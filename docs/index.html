✦ Usage

Simple by design

三个常用场景，一看就会。

基础格式化

dbsqlfmt format query.sql

自动检测方言，输出格式化后的 SQL。不指定文件后缀限制。

关键字小写

dbsqlfmt format query.sql --keyword-case lower

将关键字转为小写，数据类型和函数名保持默认大写。

预览模式

dbsqlfmt format query.sql --dry-run

仅输出到终端不改写文件。配合 DBeaver 外部工具极佳。
