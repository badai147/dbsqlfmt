dbsqlfmt

SQL 格式化命令行工具，支持 MySQL / PostgreSQL，自动识别方言

GitHub npm

特性

双方言

完整支持 MySQL 和 PostgreSQL 方言，一套工具覆盖主流数据库

自动检测

无需手动指定方言，基于加权评分系统自动识别 SQL 方言类型

关键字大写

一键将所有 SQL 关键字转为大写，提升代码可读性

可配置缩进

自定义缩进空格数，适配你的编码风格

Dry-run 模式

预览格式化结果而不改写文件，放心试用

配置文件

通过 .dbsqlfmtrc 持久化选项，团队共享配置

安装

全局安装，命令行直接使用：

npm i -g @badai147/dbsqlfmt

或本地项目安装：

npm i -D @badai147/dbsqlfmt

使用

基础格式化
dbsqlfmt format query.sql
指定方言 + 关键字大写
dbsqlfmt format query.sql --language postgresql --uppercase
预览模式（不写回文件）
dbsqlfmt format query.sql --dry-run

选项

# 所有可用选项
-l, --language <lang> SQL 方言 (mysql / postgresql)
-i, --indent <size> 缩进空格数 (默认 2)
-u, --uppercase 关键字转大写
--dry-run 仅预览，不改写文件
-V, --version 查看版本号
-h, --help 查看帮助
